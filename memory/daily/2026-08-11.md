Lesson: AWS's fault-tolerance features for Map iterations are a DISTRIBUTED-mode-only feature, not an INLINE Map feature — this is an AWS platform restriction, not an SST gap, but SST's Map component gives no hint/validation that the field would be a no-op in inline mode (and doesn't expose the field at all, see MEM-9 transform workaround).
